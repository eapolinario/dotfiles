# Skill manifest mirrored from `common/skills/` into `nixos/skills.nix`

The list of **shared skills** must be visible to three consumers — NixOS
home-manager, the macOS installer, and the omarchy installer — with
`common/skills/` as the single source of truth. NixOS's flake lives at
`nixos/`, and pure-mode flake evaluation cannot read files outside the flake
root, which rules out reading the directory directly from HM.

We mirror the directory listing into `nixos/skills.nix` (a derived artifact
generated by `make skills-sync`) and enforce no drift with
`make skills-sync-check` in CI. macOS and omarchy installers iterate
`common/skills/*/` at install time; the Nix consumer reads the mirrored list.

## Considered Options

- **Move `flake.nix` to the repo root.** Cleanest in principle (`./common/skills`
  becomes a literal nix path, no manifest needed), but invasive: touches the
  Makefile, every CI workflow, every doc reference, and the deploy script.
  Rejected for repository-restructuring cost on a single-host config.
- **Declare `common/` as a `path:../common` flake input.** Empirically broken
  for relative parent-traversal: `outPath` becomes a string-concatenated path
  that pure-mode `readDir` rejects. Adding an inner `flake.nix` to `common/`
  fails the same way.
- **Evaluate with `--impure`.** Loosens `nix flake check` semantics across the
  whole flake just to read one directory listing. Rejected.
- **Mirror manifest into the flake tree (chosen).** One small generated file
  inside `nixos/`; CI guard makes drift impossible.

## Consequences

- Adding a skill is two steps: create `common/skills/<name>/SKILL.md`, then
  `make skills-sync`. Forgetting the second step fails the
  `skills-sync-check` CI job before merge.
- `nixos/skills.nix` is **never** edited by hand. It carries a header
  comment naming `make skills-sync` as its sole producer.
- A skill is identified by the presence of `SKILL.md` at the root of its
  directory; directories under `common/skills/` without a `SKILL.md` are not
  exposed (this guards against accidental promotion of templates / drafts).
